Vrtić — od upisa do računa

Kako funkcionira

  • Upis djeteta — GDPR pristanak roditelja OBAVEZAN (čl.8 GDPR)
  • Evidencija dolazaka — svaki dan: prisutno / bolesno / opravdano / neopravdano
  • Mjesečna naplata — automatski odbitak obroka za dane izostanka
  • Račun roditelju — generira se iz MonthlyBilling → invoicing.Invoice
  • Roditeljski portal — dnevni izvještaj, obavijesti, računi
  • CSV import — bulk upis 100+ djece iz Excela

WhatsApp Roditelj dobije alert o izostanku, podsjetnik za plaćanje, dnevni izvještaj

Vrtić → KUD pipeline

Odgajateljica vidi da dijete ima osjećaj za ritam → klikne "Preporuči u KUD" → sustav kreira učenika u glazbenoj školi → roditelj dobije WhatsApp s pozivnicom na besplatnu probu.

Automatski Dijete iz vrtića postaje učenik glazbene škole bez ijednog papira.

KUD i Glazbena škola

Glazbena škola — evidencija i fakturiranje

  • Učenici — ime, instrument, razina (pripremni→napredna), instruktor
  • Sati nastave — datum, trajanje, gradivo, pedagoška bilješka
  • Fakturiranje — jednim klikom: svi nefakturirani sati → račun roditelju
  • PDV — glazbeno obrazovanje OSLOBOĐENO PDV-a (čl.40 ZPDV) ako je u registru

HTMX Inline dodavanje učenika i sati — bez reloada stranice

ZAMP prijava

Za svaki nastup sustav generira strukturirani XML s popisom izvedenih djela. XML se šalje na prijavadj@zamp.hr. Nema API-a — ZAMP prima email.

Instrumenti (pilot: KUD Dukat)

Restoran — od QR-a do kuhinje

Digitalni jelovnik

  • QR na stolu → gost skenira → vidi menu na mobitelu
  • Košarica → odabere stavke → pošalje narudžbu
  • WhatsApp kuharu → automatska notifikacija s brojem stola i stavkama
  • Kuhinjski display → real-time prikaz narudžbi, status gumbi (priprema→gotovo→posluženo)

Admin panel

Inline promjena cijena (klik → edit → spremi bez reloada). Toggle dostupnosti artikla. Upozorenje kad zaliha padne ispod minimuma.
