FINA Info.BIZ — Automatski OIB lookup
Automatski dohvat podataka firme po OIB-u za sve HR poslovne subjekte
{% if has_fina_token %} Aktivno {% else %} Nije konfigurirano {% endif %}
{# Objašnjenje #}
Zašto je ovo korisno?
EU VIES registar pronalazi samo firme koje su PDV obveznici. Mikro poduzetnici, obrti i OPG-ovi koji nisu u sustavu PDV-a (npr. KORPAŠ d.o.o., OPG Kruljac...) nisu vidljivi u VIES-u — ali jesu u FINA Info.BIZ bazi koja obuhvaća sve aktivne poslovne subjekte u Hrvatskoj.

S aktivnim FINA Info.BIZ tokenom, sustav automatski popunjava naziv, adresu i MB firme pri unosu OIB-a — čak i za ne-PDV subjekte.
{# Koraci za aktivaciju #}
Kako aktivirati FINA Info.BIZ lookup?
  1. Otvorite infobiz.fina.hr/Registration i registrirajte svoju tvrtku (besplatno, potreban OIB)
  2. Nakon potvrde e-mailom, prijavite se na infobiz.fina.hr
  3. U korisničkim postavkama pronađite API ključ / token i kopirajte ga
  4. Zalijepite token u polje ispod i kliknite Spremi
Važno — legalna napomena: API token koristite isključivo za svoju tvrtku. Token je osoban i vezan za vašu registraciju na FINA Info.BIZ. Svaki korisnik LIMIT Connect sustava mora imati vlastiti token. Dijeljenje tokena između više tvrtki nije u skladu s FINA uvjetima korištenja.
