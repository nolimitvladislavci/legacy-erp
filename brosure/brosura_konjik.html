Zašto CCX53 a ne CCX43?

Claude API prima do 20 slika po pozivu. S 32 vCPU server može simultano obrađivati 30+ AI poziva od različitih firmi, svaki s 15 slika. Na CCX43 (16 vCPU) pri vršnom opterećenju nastalo bi čekanje.

04 · Postavljanje
Što Marija treba napraviti.
1

Naruči CCX53 na Hetzner (5 min)

hetzner.com → Cloud → Create Server → Nuremberg → CCX53 → SSH key Ivan. Backup opcija: NE — koristiš Ivanov Backblaze B2. Privatna mreža: "LIMIT Connect Network".

2

Pošalji IP Ivanu (1 min)

Hetzner prikazuje IP čim server bude spreman (~2 min). Ivan konfigurira Django, Nginx, Gunicorn i spaja Backblaze B2 backup automatski.

3

Migracija aplikacije (2-4h)

Zero-downtime: DNS se prebacuje tek kad je novi server potpuno testiran. Korisnici ne osjete prekid.

Produkcija — AI na 15 slika
