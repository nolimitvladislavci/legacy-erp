Zašto 128 GB RAM za PostgreSQL?

PostgreSQL drži aktivne podatke u shared_buffers (preporučeno 25% RAM = 32 GB). Uz work_mem po konekciji (64 MB × 200 pool = 12.8 GB) i OS cache — 128 GB osigurava da baza ne mora čitati s diska za standardne upite.

04 · Postavljanje
Što Ivica treba napraviti.
1

Naruči CCX53 na Hetzner (5 min)

hetzner.com → Cloud → Create Server → Nuremberg → CCX53 → SSH key Ivan. Backup opcija: NE — Ivan koristi Backblaze B2. Privatna mreža: "LIMIT Connect Network".

2

Pošalji IP Ivanu (1 min)

Hetzner prikazuje IP čim server bude spreman (~2 min). Ivan konfigurira PostgreSQL 16, PgBouncer, optimizacije za 128 GB RAM i spaja Backblaze B2 backup automatski.

3

Migracija baze (2h)

pg_dump s trenutnog servera → pg_restore na novi CCX53. Aplikacija radi na staroj bazi dok nova nije testirana — tada jedna linija prebacuje sve.

4

POS terminali (30 min)

Ivičin POS terminal (Blagajna PM Čepin, ID:4) automatski radi s novom bazom. Nema prekida u smjenama.

✓

Produkcija — klaster aktivan

Ivan (Redis) + Marija (App) + Ivica (DB) = platforma za 20.000+ korisnika. Backup automatski svaki dan u 03:00 → Backblaze B2, WhatsApp potvrda u 07:30.
