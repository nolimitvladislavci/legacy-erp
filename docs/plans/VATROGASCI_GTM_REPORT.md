## 5. Competitor analiza — PLAVO NEBO

**Pretraga:** nema specijaliziranog softvera za DVD-ove u HR.

Alternativa DVD-ova danas:
- Excel tablice (80% DVD-ova)
- Papirni putni nalozi
- Ručno vođeni registar članova
- Nema automatskog izračuna dnevnica

**Zaključak:** LIMIT Connect je **jedini** ERP koji:
1. Razumije nefiskaliziranu naplatu članarina
2. Ima putne naloge s automatskim dnevnicama
3. Prati volonterski limit po zakonu
4. Generira izvještaje za MUP natječaje

**Plavo nebo = 0 direktnih konkurenata. Tko uđe prvi, ostaje.**
