Otvoreni kriptografski standard

Container of Truth — .dok

Za obične ljude: .dok je format datoteke (kao .pdf ili .docx) koji svaki dokument omotava u "oklop" od tri neovisna kriptografska sloja. Čak i ako izgubite internet, kompaniju ili platformu — dokument i dalje može biti verificiran. Besplatno. Zauvijek.
📦 Anatomija .dok paketa ZIP + XML + JSON-LD + WASM

Svaki .dok sadrži izvorni dokument + kriptografski manifest + WASM reader koji može verificirati sadržaj bez interneta, bez vaše firme, za 100 godina.

chain_hash = SHA-256( L1_hash + L2_phash + XML_envelope )
.dok/
  ├── master/          ← izvorni dokument (PDF, slika, XML...)
  ├── manifest.xml     ← XML pravna omotnica (OpenDOK-2026)
  ├── meta.json        ← JSON-LD semantika + svi hashevi
  ├── schema.xsd       ← XSD validacija
  └── verify.wasm      ← offline verifikator (100 god. kompatibilan)
D1 — SHA-256
Kriptografski otisak
SHA-256 hash svakog byta dokumenta. Promjena jednog znaka = potpuno drugačiji hash.
Primjer: "Ugovor.pdf" dobiva nepromjenjivi digitalni potpis
D2 — pHash
Vizualni DNK
Perceptualni hash koji prepoznaje sliku čak i nakon kompresije, rotacije ili watermark-a.
Primjer: Fotografija se prepoznaje čak i ako je malo izmijenjena
D3 — AI Embedding
Semantički otisak
Vektorska reprezentacija sadržaja u 768-dimenzionalnom prostoru — prepoznaje smisao, ne samo piksele.
Primjer: Isti ugovor prepisan rukom i dalje se prepoznaje kao isti
D4 — chain_hash
Triple DNA lance
SHA-256(L1 + L2 + XML koverta) = atomska kombinacija sva tri sloja u jedan nedjeljivi otisak.
Primjer: Lažiranje jednog sloja odmah razbija cijeli chain_hash
D5 — Citation mreža
Lanac referenci
Svaki .dok može referencirati prethodne dokumente, graditi kronološki dokazni lanac.
Primjer: Revizija Ugovora v2 dokazivo nastaje iz Ugovora v1
D6 — Tržište artefakata
Digitalno vlasništvo
Svaki .dok može biti označen kao intelektualno vlasništvo, licenciran i transferiran uz kriptografski dokaz.
Primjer: Patent koji se može prodati uz automatski prijenos vlasništva
D7 — Self-Healing
Samoobnova
Shamir Secret Sharing dijeli dekripcijske ključeve između više čuvara — dokument preživi nestanak bilo kojeg od njih.
Primjer: Tvrtka se ugasi, ali 3 od 5 suradnika imaju fragment — arhiv živi
D8 — Kognitivni suverenitet
Vaši podaci, vaša pravila
Zero-knowledge arhitektura: NO LIMIT nikada ne vidi sadržaj vaših dokumenta, samo hash.
Primjer: Verificiramo da dokument postoji, ne što piše u njemu
D9 — Shamir Key
Distribuirani ključevi
Privatni ključevi podijeljeni matematički — nitko nema cijeli ključ sam, a N od M čuvara može rekonstruirati.
Primjer: Digitalna oporuka koja se aktivira samo uz pristanak 3 svjedoka
