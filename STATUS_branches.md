### Problem 1: `NameError: get_object_or_404` — GLAVNI UZROK 500 ✅ POPRAVLJENO

**File:** `/var/www/fina-connect/core/views.py` — funkcija `superadmin_company_branches()`

**Uzrok:** Funkcija koristi `get_object_or_404(Company, pk=company_id)` na liniji 843,
ali ni top-level ni lokalni import za `get_object_or_404` nije bio u toj funkciji.

Ostale funkcije u istoj datoteci koriste lokalne importove unutar funkcija,
ali `superadmin_company_branches` taj import nije imao.

**Popravak:** Dodan lokalni import unutar funkcije:
```python

from django.contrib import messages as _msg

# POSLIJE (dodano):

from django.contrib import messages as _msg
from django.shortcuts import get_object_or_404       # ← NOVO
```
